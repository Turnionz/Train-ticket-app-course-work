# Курсова Робота на тему Залізнична каса: продаж та бронювання проїзних білетів на потяги

---

Цей проєкт є виконанням курсової роботи з дисцпиліни Інженерія Програмного Забезпечення на тему Залізнична каса: продаж та бронювання проїзних білетів на потяги.

При виконанні цієї курсової роботи було використано PHP 8.2, Laravel 12, Livewire 4.2.0, Postgresq; 15 та Tailwindcss.
